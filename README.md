# 🌌 Cosmic Zoom: Galaxy to Planet Explorer

An interactive 3D WebGL space explorer that lets you seamlessly zoom from the grand spiral structure of the Milky Way Galaxy down to individual planets in our Solar System. Inspired by spatial mapping tools like Google Earth, **Cosmic Zoom** provides a fluid sense of scale across the universe.

🚀 **[Live Demo](https://tonyeng06-star.github.io/cosmiczoomgalaxyexplorer/)**
